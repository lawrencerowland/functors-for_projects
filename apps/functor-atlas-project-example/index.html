These are membership relations, not four images of one object under a D → T functor.

About this repaired project sketch

This merges the original project example’s clickable edge details and region dragging with the later draft’s 14 filters and three layouts. The generic earlier sketch is not used. Original project names, quantities and candidate mapping families are retained.

Connections are declared explicitly. Cost accrual uses the matching schedule intervals; stakeholder update arrows have explicit endpoints; W task sets are expanded into membership links. Z3 makes the originally named daily commit histogram visible. “PERT aggregation” remains an operation annotation on M1 because the draft supplies no input estimates or aggregation rule. It is not a computed forecast.

Some views contain relations that are not directed morphisms (such as overlap and trade-off), and some connections cross views. Object mappings alone do not define functors: arrow mappings, identities and composition would also need to be specified and checked. H’s original contravariant label and Δ’s change notation are retained as proposals in the details, without asserting those structures.
